# 开放题版 MBTI · 行为叙述测评

把选择题换成受测者自己写的场景。每一题给一个情境框定，你写下自己在类似情境下**会产生的行为与想法**；
模型读的是你的原话，按 MBTI 原有的维度框架给出倾向、置信度，以及一份能逐句追溯到原文的人物小传。

> 这是一份**倾向画像**，不是类型判定，也不是任何形式的诊断。
> 产出没有信效度检验，**不适用于招聘筛选、升学分流等高风险决策**。

## 两种运行方式

同一份代码，两种部署形态，判型规则完全一致（共用 `public/lib/` 下的同一份实现）。

### 一、本机运行（推荐用于自用）

```bash
git clone <本仓库>
cd mbti-open
npm start
```

打开 http://127.0.0.1:5173

- 服务端**只监听 127.0.0.1**，不对外暴露。
- 密钥由服务端从本机配置读取（依次尝试 `MBTI_API_KEY` 环境变量 → `.env.local` →
  `%USERPROFILE%\.minimax\agents\coder\config.yaml`），**浏览器拿不到密钥**。
- 作答不落盘；草稿存在浏览器 localStorage 里。

### 二、静态部署（GitHub Pages）

仓库的 `public/` 目录就是站点根目录，由 GitHub Actions 发布。

- 页面是**纯静态**的，没有后端。
- 访客需要填**自己的** MiniMax API Key。Key 只存在访客的浏览器 localStorage 里，
  不经过任何服务器，**仓库和页面上都没有密钥**。
- 判型请求由浏览器直接发往 `api.minimaxi.com`（该端点支持 CORS）。

访问地址形如 `https://<你的用户名>.github.io/<仓库名>/`。

本地想验证静态链路时，加 `?mode=direct` 强制走直连模式（`?mode=local` 强制走本机服务）：

```
http://127.0.0.1:5173/?mode=direct
```

## 交互流程

1. **开始页**：说明玩法与边界；静态部署版在此填写 API Key。
2. **逐维作答**（E/I → S/N → T/F → J/P）：每组 6 题，一屏一题，含写作指引与三项最小信息自检。
3. **提交即跳转**：一维填完点「提交并继续下一维」，**立刻进入下一维**，本维判型在后台并行计算，
   页面顶部状态条实时显示 `待答 / 作答中 / 计算中 / 完成 / 失败`。
4. **失败可重试**：某维判型失败时给出原因与「重试评判」按钮，作答不会丢。
5. **一次性汇总**：四维齐备后自动合成报告——类型字母、整体置信度、四维读数表、人物小传、
   证据边界、四个维度的完整判型依据（支撑证据 / 反向证据 / 易误读核对 / 证据缺口）、引证表。
6. **重新合成**：报告页可「重新合成报告」，复用已有作答不必重答 24 题。

## 设计要点

- **维度锁定靠结构，不靠提示词**：一次判型请求只接收一个维度的 6 题，输入里不存在其他维度的作答，
  模型无从跨维度推断；提示层再叠加该维专属的维度透镜、每题锚点与误读防护。
- **引文可溯源靠程序校验**：模型给出的每条引文必须在作答原文中**逐字命中**（规范化后子串匹配，
  最短 4 字）；命中失败即丢弃该条并下调该维置信度。引证表里的每一条都能回查。
- **类型字母由逐维倾向拼出**，不采信模型单写的 `type` 字符串。取值优先级：
  单维判型结论 → 汇总阶段的逐维结论 → 模型写的字母（须属于本维度两极）。
  这保证了报告顶部的大字母与「四维读数」表在结构上不可能自相矛盾。
- **小传每段必须带可溯源引文**，且至少有一段要写出证据薄弱、彼此矛盾或随情境变化的地方；
  不过关则重生成一次，仍不过关就降级为只拼原话的保守版。
- **服务端与浏览器共用一份判型实现**（`public/lib/`），因此本地跑出来的结果与线上跑出来的结果口径一致。

## 目录结构

```
server.mjs          本机服务端（只监听 127.0.0.1）
lib/config.mjs      仅服务端：解析凭证与端点配置
public/             ← GitHub Pages 的站点根目录
  index.html
  app.js            前端状态机与渲染（双模式：local / direct）
  styles.css
  items.json        24 道题：4 维 × 6 题
  lib/
    prompts.js      提示词与四套维度透镜
    validate.js     引文校验、类型派生、降级
    llm.js          API 调用层（协议适配、超时、重试、脱敏）
    pipeline.js     判型流程：服务端与浏览器共用的唯一实现
test/               离线测试（不依赖真实 API）
```

## 题目来源与致谢

- 题目以**标准 MBTI 的维度构念与题位分布**为骨架，逐题重写为原创开放情境题，不复制任何原题表述。

  本项目是**原创的开放题改编与研究性工具**，与 Myers & Briggs Foundation 无任何关联。

## 隐私

- 作答只发往判型 API 端点（本机部署时是本机服务与你的账号；静态部署时是你自己填 Key 的那个端点）。
- 任何情况下作答都不落在服务器上；草稿保存在访客自己的浏览器里。
- 仓库里不存在任何凭据，`.env.local` 已被 `.gitignore` 排除。
